VFD Quick Reference – 0–10 V, Start, Run Status

Generic step-by-step checklists for common VFD families. Always confirm terminal numbers and parameter IDs in the manual for your exact model before applying live.

Danfoss (VLT FC series – FC301/FC302 style)
  1. 0–10 VDC speed reference
    1. Wire the 0–10 V signal into an analog input terminal that supports voltage (for example, terminal 53 or 54 on FC302; ensure its small selector switch is set for voltage, not current).
    2. In the analog input menu, set the input type to 0–10 V and assign that analog input as the main speed reference.
    3. Set minimum and maximum reference values so 0 V = minimum speed (often 0 Hz) and 10 V = maximum speed (your max Hz setting).
    4. If needed, adjust filtering and deadband so the motor doesn’t “hunt” with small noise on the signal.
  2. Start / run command input
    1. Pick a digital input and its common (dry contact between DI and COM).
    2. In the digital input configuration, set that DI’s function to Start / Run or Coast/Stop + Start, depending on your sequence style.
    3. Set the polarity (normally open vs normally closed) to match your field contact.
    4. Set the drive’s “command source” so it accepts run commands from terminals (not only from the keypad or fieldbus).
  3. Run status output
    1. Choose either a relay output or a digital output terminal to use as the “drive running” signal.
    2. In the output configuration, assign its function to Drive running / Run status (true whenever the drive has a valid run command and output frequency > 0).
    3. Wire the output contacts back to your PLC/HMI input or interlock circuit.
    4. Test: command the drive to run and verify the run status changes state when the motor actually runs.
Yaskawa (V1000 / GA-style drives)
  1. 0–10 VDC speed reference
    1. Wire the 0–10 V signal to the analog input terminal (for example A1) and its common (ACOM).
    2. In the parameters, set the speed reference source to “external terminals” (on many Yaskawas this is a b1-xx parameter; check the sheet for your model).
    3. Set the analog input mode to voltage and the scaling so 0 V = min freq and 10 V = max freq.
    4. Verify by monitoring the frequency command monitor on the keypad while sweeping the 0–10 V signal.
  2. Start / run command input
    1. Wire your start contact to one of the digital inputs (for example S1) and the digital common (SC).
    2. Choose 2-wire or 3-wire control style in the run command parameters (Yaskawa uses b1-17 / similar for this).
    3. Assign the selected DI as “Forward run” (and optionally another DI as “Reverse run” if you need bi-directional control).
    4. Set “run command source” to “terminals” so the drive listens to S1/SC instead of keypad only.
  3. Run status output
    1. Pick a multifunction output (digital output or relay, depending on your frame size).
    2. In the output function parameters, assign that output to “Run” or “Drive running”.
    3. Wire the output into your PLC input or permissive chain (for example, “OK to start burner when VFD running”).
    4. Test by starting and stopping the drive to verify the output follows the motor run state.
Toshiba (VF-S series – e.g., VF-S15)
  1. 0–10 VDC speed reference
    1. Wire the 0–10 VDC signal to an analog input capable of 0–10 V (for example VIA or VIB) and its common.
    2. Use the analog input selection parameter (on VF-S15 this is an f10x/f109-type setting) to define that terminal as a voltage input, not logic or current.
    3. Assign that analog input as the frequency command source and set min/max scaling for 0–10 V = 0–max Hz.
    4. Confirm response by monitoring the command frequency on the display while changing the input voltage.
  2. Start / run command input
    1. Wire your start contact between a digital input (for example F or a programmable DI) and its common.
    2. Set the operation command source to “external terminals” so the VFD listens to the DI instead of the keypad.
    3. Assign that DI’s function as “Run” (or “Forward run”) and match the contact logic (NO/NC) in the parameter.
    4. Check that the run LED and output frequency change when you close the start contact.
  3. Run status output
    1. Select a relay output or open-collector digital output for run status.
    2. In the output function parameter list, map that output to “Running” / “Operation status”.
    3. Wire it to your PLC input or interlock as a dry contact or open-collector signal according to the manual’s wiring diagram.
    4. Test: start the drive and verify the output changes state only when the motor is actually commanded to run.
Schneider / Altivar (ATV / Altivar Process – e.g., ATV630)
  1. 0–10 VDC speed reference
    1. Wire the 0–10 V signal to an analog input (commonly AI1) and COM per the Altivar wiring diagram.
    2. In the drive menu (often under Complete settings → I/O → AI/AQ), set AI1 to 0–10 V and assign it as the main speed reference.
    3. Set low and high scale values so 0 V corresponds to min speed, 10 V to max speed.
    4. Verify using the drive’s monitoring screen that the “Speed reference” value tracks the 0–10 V signal.
  2. Start / run command input
    1. Wire a dry contact between a digital input (for example DI1) and its common (COM).
    2. In the I/O configuration, assign DI1’s function to “Run” (2-wire) or to the appropriate 3-wire start/stop scheme you use at your plants.
    3. Set the command channel so the drive accepts run commands from terminals instead of just the HMI or fieldbus.
    4. Confirm that closing the contact starts the drive and releasing it stops it according to your chosen mode.
  3. Run status output
    1. Pick a relay output (R1/R2, etc.) or logic output as your “Drive running” signal.
    2. In the output assignment menu, set that output function to “Drive running” or “Motor running”.
    3. Wire the contacts into your PLC/HMI or interlocks exactly as a standard dry contact.
    4. Test the behavior across run, stop, and fault conditions so the PLC logic matches how the drive signals “running”.

4–20mA Configurations

Step-by-step setup for 4–20mA analog inputs as speed reference on Danfoss, Yaskawa, Toshiba, and Schneider drives.

Danfoss (VLT FC series) – 4–20mA

How to Configure

  1. Wiring
    1. Land the + (positive) of your 4–20mA loop on terminal 53 or 54 (whichever supports current on your unit).
    2. Land the – (negative) on terminal 39 (analog common).
    3. Ensure the small physical switch on the side of the analog input card is set to current (mA), not voltage.
  2. Parameters
    1. Set the analog input mode to 4–20mA.
    2. Assign this analog input as the Main Speed Reference.
    3. Set minimum value = 4 mA = 0 Hz (or your plant’s minimum speed).
    4. Set maximum value = 20 mA = max Hz (60 Hz or your max belt speed setting).
    5. Enable filtering (low-pass) if your signal is noisy or the speed “hunts”.
Yaskawa (V1000 / GA800) – 4–20mA

How to Configure

  1. Wiring
    1. Wire loop + to terminal A2 (4–20mA analog input).
    2. Wire loop – to terminal AC (analog common).
    3. Make sure your transmitter/loop power supply shares the proper common reference.
  2. Parameters
    1. Set the analog input mode for A2 to Current (4–20mA).
    2. Set the drive’s Reference Source = “External Analog Input”.
    3. Scale 4mA = low frequency (0 Hz or min speed), 20mA = high frequency (max speed).
    4. Set filtering/smoothing to avoid jitter, especially at low speed.
Toshiba (VF-S series) – 4–20mA

How to Configure

  1. Wiring
    1. Wire the 4–20mA + signal to VIA (or the designated mA analog input for your model).
    2. Wire the 4–20mA – to analog common.
    3. Verify your loop power and commons are referenced correctly.
  2. Parameters
    1. Set the analog input mode to mA (4–20mA) in the appropriate f10x/f109-type parameter (depends on the exact VF-S model).
    2. Assign VIA/VIB as the Frequency Command Source.
    3. Scale 4mA → minimum speed, 20mA → maximum speed.
    4. Adjust filtering if the motor/belt speed is unstable at low mA values.
Schneider / Altivar (ATV630 etc.) – 4–20mA

How to Configure

  1. Wiring
    1. Wire loop + to an analog input rated for mA (for example AI2, depending on model).
    2. Wire loop – to COM.
    3. Check jumpers or configuration options to be sure the input is in “current” mode, not voltage.
  2. Parameters
    1. In I/O Config → Analog Inputs, set the selected AI to 4–20mA Current Mode.
    2. Assign this analog input as the main speed reference channel.
    3. Set min/max scaling so 4mA = minimum frequency and 20mA = maximum frequency.
    4. Enable filtering if the cable run is long or noisy.

Always confirm terminal labels and parameter numbers for your exact VFD model. These sequences reflect common patterns and are meant as a field memory aid.
